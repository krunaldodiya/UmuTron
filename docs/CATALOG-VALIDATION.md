No source links, user Library data, credentials, real games or downloads were accessed by this delta.

## Endpoint environment delta

`APP_BASE_URL` is now the primary origin-only backend setting. The former `UMUTRON_CATALOG_URL` is accepted only when the primary is unset. Empty/invalid primary settings never silently fall back. Endpoint suffixes remain the agreed `/v1` routes. Production HTTPS behavior is unchanged; explicit `UMUTRON_ALLOW_LOOPBACK_HTTP=1` allows only validated loopback HTTP for local integration.

146 core tests pass, including seven new endpoint/transport tests: exact origin/path joining, HTTPS by default, canonical localhost/IPv4/IPv6 loopback, blocked LAN/remote/ambiguous/scoped/mapped hosts, rejected base paths/credentials/query/fragment/ports/controls, primary/legacy precedence and exact opt-in, real disposable loopback GETs under hostile proxy settings, absent credential/cookie headers, refused redirects and bounded response size. The local servers are shut down by test cleanup; no upstream or real credentials are used. Ruff F and compilation pass. The native acceptance fixture also passes; no UI composition, lifecycle, uninstall or history logic changes in this delta.

The original frozen catalog candidate remains unchanged. The delta contains only its specific source/test/documentation files and excludes generated caches. Apply it against the recorded frozen file hashes; it is not an installation or publication action.
